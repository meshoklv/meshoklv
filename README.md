# Hi, I'm Mike Meshok

Full-stack developer and AI-tooling tinkerer. I build business software for logistics, plus a lot of automation around LLM agents, Telegram and iOS.

## What I work on

- **Logistics CRM** - a web CRM (Next.js / TypeScript) with a companion native iOS app (SwiftUI) for a freight company.
- **AI agents and tooling** - a terminal portal for running coding agents from a phone, a voice agent for outbound calls (STT -> LLM -> TTS), and a safety layer that vets risky agent actions.
- **AI model benchmarking** - checking whether coding agents damage production-like data when given vague tasks, and comparing models for coding and speech recognition.
- **Telegram bots** - notifications, task flows and integrations.
- **Network and privacy research** - experimenting with VPN transports and clients (Go, Kotlin, Swift).
- **Local models and media** - self-hosted LLMs and image generation on a consumer GPU; small Blender / 3D-printing projects.
- **VibeNokia** - an AI vibe-coding terminal running on a Nokia 3310 (2017).
- **KINO.js** - a cinematic motion engine built for AI-generated scenes.
- **Health monitor** - daily AI health analysis from a Mi Band 10, delivered via Telegram.
- **Games** - small browser games in TypeScript.

Most of this work is in private repositories.
